# 큰 비교 사진 · 부위 표시 · 짧은 수정 지시

10/26 무신사 사진 중심 방식과 10/23 후그 사진 옆 짧은 피드백을 10/27 사용자 요청으로 공통화했다. 개별 판정은 재사용하지 않는다.

## 기본 화면

상단은 브랜드/차수 · 착장 · 컷번호 · 현재 판정만 둔다.

| 현재 사진 · 빨강 | 기준 사진 · 파랑 | 실행 지시 |
|---|---|---|
| 큰 사진, 문제 위치 ① | 동일 부위 큰 사진, 대응 위치 ① | ① 부위 → 수정 방향 |
| 필요한 부위 확대 | 출처·품번·참고 목적 | 현재 차이 / 유지 요소 각 한 줄 |

사진이 화면 대부분을 차지한다. 문장이 늘면 상세를 접거나 다음 장으로 보내고 사진을 줄이지 않는다. 실제 화면 크기에 맞추며 픽셀값을 모든 산출물에 고정하지 않는다. 좁은 화면에서는 지시를 아래로 보낸다.

- 전신은 위치 파악용, 확대는 구조·로고·밑단·손 등의 판정용이다. 확대에서도 컷번호와 전체 사진 접근을 유지한다.
- 여러 문제는 주제별 전환/별도 장으로 나누고 모든 화살표를 겹치지 않는다.
- 표시 좌표는 컷별 관찰로 정한다. 같은 좌표를 모든 포즈에 복제하지 않는다. 웹 표시선은 이미지 영역 기준으로 연결해 창 크기가 바뀌어도 부위와 일치시킨다.
- 비교 크롭에서 인물·옷을 변형하지 않는다. 표시용 복사본과 원본을 구별하고 Figma 표시선은 별도 레이어로 남긴다.
- 기준에 `같은 품번 · 소매 길이만`, `다른 색상 · 절개만`, `모델 기준 · 핏 참고 아님`, `비교용 미확정`처럼 적용 범위를 적는다.

## 짧은 지시 예시

내부 근거는 부위·현재 차이·수정 방향·정확한 참고·유지 요소·완료 기준을 남기되 화면은 실행 문장을 먼저 보여준다. 아래는 형식 예시이며 실제 관찰된 경우에만 쓴다.

| 피할 표현 | 실행 문장 예시 |
|---|---|
| 핏 자연스럽게 | ① 밑단 — 안쪽 말림을 풀어 무릎 아래 통이 세로로 이어지게 해주세요. |
| 얼굴 이상함 / 10% 축소 | ① 얼굴 — 확정 모델과 머리·어깨 비율을 맞춰주세요. 시선·헤어는 유지해주세요. |
| 디테일 재확인 | ① 포켓 — 제품 사진처럼 입구의 이중 상침을 복원해주세요. 포켓 위치는 유지해주세요. |
| 조명값 수정 | ① 얼굴·목 — 옷과 빛 방향을 맞추고 붉은기·과한 광택을 줄여주세요. 제품색은 유지해주세요. |
| 로고 누락 확정 | ① 로고 — 옆으로 돌아 가려진 것인지 확인해주세요. 실제 누락일 때만 제품 사진대로 추가해주세요. |

‘고급감’, ‘모델스럽게’, ‘자연스럽게’만 적지 않는다. 제공되지 않은 밝기값·cm·축소율은 만들지 않는다. 유지 메모는 해당 수정에서 망가지기 쉬운 요소만 쓴다. BBC 작업장에서는 반복 유지/상태 설명을 생략하고 실제 수정 문장만 남긴다.

## 전달 형식과 이력

- PDF는 현재/기준/지시를 같은 페이지에서 연결하고 모든 요청 컷을 포함한다. 페이지에 우겨 넣지 말고 큰 사진 쌍 중심으로 구성한다.
- HTML은 착장/컷/주제 전환·현재/기준 확대·짧은 지시, 상세 근거/이전본/출처 펼침을 제공한다. 선택된 한 컷만 인쇄하는 기능을 전체 검수 PDF 내보내기라고 부르지 않는다.
- 작업용 원본 품질을 유지한다. 보기용 미리보기는 원본 접근을 제공하고 저해상도로 작업 원본을 대체하지 않는다.
- 작업장에서는 착장 자료 → 이전 수정·전달 → 최신 피드백 → 이번 수정 → 최종 전달의 관계를 보존한다. 입증되지 않은 과거본을 임의로 1·2·3차로 이름 붙이지 않는다.
- 새 차수 칸을 요청받았다면 빈 진행 공간임을 표시한다. 기존 최종본을 새 결과로 덮어쓰지 않는다.

## 가시성 확인

기본 배율에서 어느 사진의 어떤 부위를 어떻게 고칠지 바로 보이는지, 번호가 실제 부위와 대응하는지, 기준 버전/참고 목적이 정확한지, 글과 표시가 사진을 가리거나 잘리지 않는지 확인한다. 전달 파일을 다른 위치에서 열어도 필요한 자료를 볼 수 있어야 한다.
